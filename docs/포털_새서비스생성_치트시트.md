## 4.1 소스 및 배포 설정
| 항목 | 입력값 |
|---|---|
| 배포 트리거 | **자동** (브랜치 push 시 자동 배포) |

| 레포지토리 | **INPMS** (이관된 회사 레포) |
| 브랜치 | **main** |
| 소스 디렉터리 | **/** (루트) |

**기본 정보**
| 항목 | 입력값 |
|---|---|
| 서비스 이름 | **`inpms`** *(4~40자·영문시작·영문/숫자/하이픈)* |

## 4.2 빌드 설정
- **방식: "구성 파일 사용" 선택** → 레포 루트의 `apprunner.yaml` 자동 인식
- 프레임워크 수동 선택 불필요 (yaml에 runtime/build/run 모두 정의됨)
- 참고 — yaml 내용:
  - runtime: `python311`
  - build: `pip install -r server/requirements.txt`
  - run: `uvicorn server.main:app --host 0.0.0.0 --port 8080`
  - port: `8080`

## 4.3 환경 변수 / Secrets
- **DB 미연결로 먼저 배포해도 됨** → 정적 화면 동작, `/api/*`만 503
- DB 연결 시: `apprunner.yaml`의 `run.secrets` 주석 해제 후 ARN 입력 → push
  ```yaml
  run:
    secrets:
      - name: DATABASE_URL
        value-from: "arn:aws:secretsmanager:ap-northeast-2:<account>:secret:inpms-db-xxxxxx"
  ```

## 4.7 네트워크 설정

## 배포 후 확인
- [ ] 기본 도메인 접속 → 화면(대시보드) 뜨는지
- [ ] `https://<도메인>/api/health` → DB 미연결 시 `{"db":"unconfigured"}`, 연결 시 **`{"db":"connected"}`**
- [ ] (DB 연결 후) 기존 데이터 이관: `POST /api/import` 에 앱 [백업] JSON 업로드
- [ ] 로그 탭 → 배포/애플리케이션 로그에 에러 없는지

## 7. 사용자 지정 도메인 (선택)
- 사용자 지정 도메인 탭 → **`inpms`** → `inpms.cosmaxhub.com` (SSL 자동 발급, 수 분 소요)

## 문제 시 (가이드 FAQ)
- **Create failed** → 로그 탭 배포로그 확인 (대개 apprunner.yaml/시작명령 오류)
- **배포 성공·접속 불가** → 프라이빗 엔드포인트는 사내망(VPN)에서만 접근 / 포트 8080 확인
- **엔드포인트 Failed** → 상세 페이지 "연결 재시도"
- 문의: I&S팀 이기동 팀장, 손용혁 과장
