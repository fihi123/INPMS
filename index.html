🔄 TO-BE 프로세스 (재정립)

전체 신제품 → 단계별 위험도 평가 → 시생산 요청서 작성으로 이어지는 깔때기형 프로세스입니다.

1

신제품 리스트 입력 (주단위)

매주 신제품을 전체 등록. 누구나 입력 가능 (마케팅/해외영업/연구소). 최소 정보(제품명·브랜드·고객사·발매일).

2

1차: R&D 위험도

연구소가 신제품마다 R&D 위험도 평가 (낮음/보통/높음/심각) + 코멘트. 완료 후 2차 평가 잠금 해제.

3

2차: 공정·품질 (병렬)

공정개발팀과 품질팀이 병렬로 평가. 각자 4단계 등급 + 코멘트.

4

최종 위험도 자동 산정

세 평가 중 최댓값(max)이 자동 최종 위험도. 셋 다 완료되면 "평가 완료" 상태.

5

시생산 요청서 작성

평가 완료 항목 중 시생산이 필요한 건만 선택해 요청서로 promote. 위험도/제품정보 자동 채움 후 보완 입력.

📌 역할 및 책임

  • 작성자 (마케팅/해외영업/연구소) — 신제품 리스트 입력 (주단위). 권한 강제 없음.
  • 연구소 — 1차 R&D 위험도 평가
  • 공정개발팀 — 2차 공정 위험도 평가 (R&D 완료 후)
  • 품질팀 — 2차 품질 위험도 평가 (R&D 완료 후, 공정과 병렬)
  • 참조자 (생산팀/KS팩) — 읽기 전용

📌 시생산 단계 재발 방지 원칙 (요청서 진행 시)

  1. 표준 요청서 필수 — 팀즈/유선만으로 진행 금지
  2. 더블체크 서명 — 작성자·검토자·승인자 이중 확인
  3. 생산 CAPA 기재 필수 — 라인 확인 없이 진행 금지
  4. 주 1회 진행상황 업데이트 — 지연 건 조기 발견
  5. 실패 사례 공유 — 재발 방지 학습
